
# POV Narration Refiner

SillyTavern extension for refining user-authored roleplay narration.

## Installation

1. Copy the `pov-narration-refiner` folder.
2. Place it inside:

   `SillyTavern/data/<user>/extensions/`

3. Open SillyTavern.
4. Enable POV Narration Refiner in Extensions.
5. Refresh the page.

## Usage

1. Click the floating ✎ button.
2. Enter your narration.
3. Click ปรับคำบรรยาย.
4. Review the result.
5. Click คัดลอก.
6. Paste into chat manually.

## Features

- Separate popup window
- Draggable floating launcher
- Draggable popup
- Resizable window
- AI narration refinement
- Copy output
- Does not send messages automatically

## Compatibility

This prototype uses the SillyTavern `generateQuietPrompt` context API.

The exact generation API may differ between SillyTavern versions.
If generation fails, check the browser console.
